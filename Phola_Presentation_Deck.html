Problem Statement

South Africa's Transit & GBV Safety Crisis

Vulnerability after dark, delayed emergency response, and evidence destruction.

🚨 Critical Context
🛑
1 in 3 Women
South Africa suffers from pandemic-level rates of Gender-Based Violence (GBV). Victims frequently travel alone and lack safe, discreet intervention channels.
🚕
Night Transit Risk
Millions of commuters rely on e-hailing (Uber/Bolt) and minibus taxis. Unauthorized route deviations, unregistered drivers, and dark transit corridors pose severe risks.
⏱️
45+ Min 10111 Delay
Calling 10111 or 112 during an active attack or robbery is dangerous, slow, and fails to transmit real-time satellite GPS coordinates to first responders.
📱
Evidence Destruction
Perpetrators routinely seize, search, or destroy victim devices. Traditional photos and text messages are lost, undermining legal prosecution in courts.

Solution Architecture

Introducing Phola: An Autonomous Digital Bodyguard

A multi-layered safety shield designed specifically for South African commuters.

✨ Core Solution
🛰️
SafeRide Watchdog
Monitors trips autonomously. If your driver deviates from the expected route or stops in an unlit corridor, Phola automatically checks in and pings your emergency circle.
🗺️
Native Police Navigation
1-tap routing directly inside Phola to the nearest SAPS police station or trauma clinic. Continuous turn-by-turn guidance keeps the user protected inside the app.
🚨
Silent 1-Tap SOS
Instant multi-channel panic alerting SAPS (10111), Emergency Medical (112), and the National GBV Command Centre (0800 428 428) with live satellite coordinates.
🔒
Zero-Knowledge Vault
Audio notes, photo logs, and incident diaries are encrypted on-device via Web Crypto SHA-256 and AES-GCM before syncing to the cloud. Tamper-evident and secure.
🌦️
Stealth Decoy Exit
Under physical threat or phone inspection, 1 tap on "Quick Exit" instantly wipes DOM trace states and presents an innocent local weather forecast within 50ms.
🇿🇦
11 Official Languages
Full native accessibility in isiZulu, isiXhosa, Afrikaans, Sepedi, Setswana, Sesotho, Xitsonga, siSwati, Tshivenda, isiNdebele, and English.

Technical Architecture

Production Technology Stack & Resilience

Modern, hybrid, and fault-tolerant architecture built for offline durability.

⚙️ System Design
Frontend & Hybrid
Next.js 16 + Capacitor 5
• React 19 with Turbopack for sub-second build and execution.
• Capacitor 5 Android & iOS bridges compile native native packages.
• Tailwind CSS + Radix UI with South African design palette (`#0D6E6E`).
• Progressive Web App (PWA) with offline caching.
Backend & Storage
Supabase PostgreSQL
• Row-Level Security (RLS) enforcing strict user-isolated boundaries.
• Supabase Auth JWT with automatic stale token invalidation.
• Cloudflare Workers edge proxying for low-latency dispatch.
• Realtime subscriptions for trip tracking.
GIS & Routing
Resilient Geolocation Engine
• Continuous GPS heading & speed telemetry via Geolocation API.
• Mapbox Directions API with automatic fallback to OSRM nodes.
• Offline straight-line compass fallback if network drops completely.
• Turf.js spatial calculation for nearest police station discovery.
Zero External Map Dependency

Unlike competing panic buttons that divert to Google Maps, Phola navigates entirely within the secure app container.

Security & Compliance

Secure SDLC & POPIA Compliance

Adherence to South African Privacy Law and Defense-in-Depth Cryptography.

🛡️ SSDLC Certified
1. Requirements
• Data Minimization: Zero passive background tracking without active trip.
• Explicit POPIA consent gathered on sign-up.
• Right to be Forgotten: 1-tap complete data purge in Settings.
2. Architecture
• STRIDE Threat Modeling applied across all data flows.
• Zero-Knowledge cryptography: Web Crypto AES-GCM client-side encryption.
• Row-Level Security (RLS) on all database tables.
3. Implementation
• Salted SHA-256 PIN hashing (`${userId}:phola-pin-salt:${pin}`).
• WebAuthn Passkeys & Biometrics (`PublicKeyCredential`).
• Strict TypeScript with zero any-casts in crypto routines.
4. Verification
• Automated SAST & type-checking (`tsc --noEmit`).
• Next.js static page bundle auditing (28 routes verified).
• Native Android APK compiled with Gradle 8 and Java 17.
